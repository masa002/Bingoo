# Bingoo

社内のビンゴ大会向けのビンゴです。いまあるのは、サーバーなしで動く一人用のデモです。

- デモ: https://masa002.github.io/Bingoo/
- 演出ギャラリー（演出と音を 1 つずつ再生できる）: https://masa002.github.io/Bingoo/?gallery

## デモでできること

1 画面に「主催コンソール」「会場の大画面」「あなたのスマホ」を並べ、一人で全部の役を試せます。あなた以外の参加者（既定 1,000 人、最大 1 万人）は、ブラウザの中で動く仮想の参加者です。

- **虹は「画面の持ち主は必ず当たる」**
  - 大画面の虹は全員確定です。虹玉で、全員のカードが 1 マス開きます。
  - スマホの虹は、あなたのビンゴ確定です。
- **手元のスロット**: 抽選のたびに、あなたのスマホでスロットが回ります。
  - 連打でゲージを溜めると、予告が上がっていきます。予告の熱さは、その番号があなたのカードにとって何を意味するかで決まります。
  - STOP で自分の番号を開けます。押さなくても、締め切りで自動で止まります。
  - 大画面は「STOP した人」の数を見せてから、答え合わせをします。
- **モグラ**: 一部の人の開いた穴を埋める BAD イベントです。次の 1 球で景品が一気に減りそうなときは自動で出て、リーチの人の一部を止めます（景品の減り方の調整役）。
- **景品**: ビンゴしたら、スマホでオリパ風のパックを開けて下位（C・R）を受け取ります。
  - 10 秒以内に「受け取る」か「上位チャレンジ」を選びます。
  - 上位チャレンジでは、まだ出ていない数字で作った 3×3 のカードで SR・UR を狙います。
  - 景品が足りないときは、1 つ上のランクに上げて渡します。
- **ダブルチャンス**: 最後に、エントリーした人が各自のスマホでガラポンを回します（連打で回ります）。
- **操作パネル（デモ専用）**: 次のことができます。
  - 次の番号や演出の段階を指定する
  - 自分をリーチ・ビンゴにする
  - 全員確定やモグラを起こす
  - 早送りする

キー操作は Space で次へ、P で PUSH です。URL に `?seed=abc&size=1000&lower=30&upper=8` を付けると、同じ展開を再現できます。

## 構成

- `src/core/`: ゲームの規則（カード、判定、演出の段階、景品の在庫）。通信や描画には依存しません。
- `src/fx/`: 演出の部品（大画面の抽選機・イベント・ダブルチャンス、スマホのカード・あおり・景品・ガラポン）。ゲームの処理からは独立していて、使い回せます。共通のルールは `src/fx/GUIDE.md` にあります。
- `src/audio/`: 効果音と BGM。すべて Web Audio で合成していて、音声ファイルはありません。
- `src/demo/`: デモの権威。本番ではサーバーが担う部分を、ブラウザの中で動かします。
- `src/ui/`: 3 つの画面。メッセージを受けて、演出の部品を呼びます。

## 開発

```sh
npm install
npm run dev      # http://localhost:5173（?gallery でギャラリー）
npm run build    # dist/ に出力
```

main に push すると、GitHub Actions がビルドして GitHub Pages に出します。
