# Bingoo

社内のビンゴ大会向けのビンゴです。いまあるのは、サーバーなしで動く一人用のデモです。

デモ: https://masa002.github.io/Bingoo/

## デモでできること

- 1 画面に「主催コンソール」「会場の大画面」「あなたのスマホ」を並べて、一人で全部の役を試せます。
- あなた以外の参加者（既定 1,000 人、最大 1 万人）は、ブラウザの中で動く仮想の参加者です。
- 番号を出す前に、その番号で何人がリーチ・ビンゴになるかを計算して、演出の段階（青・緑・赤・金・虹）を決めます。虹は本当にビンゴが出るときだけ出ます。
- ビンゴした人は景品パックを開けます（C・R・SR・UR。数の決まった在庫から割り当てます）。
- 操作パネル（デモ専用）で、次の番号や演出の段階の指定、自分をリーチにする、早送りなどができます。

キー操作は Space で次へ、P で PUSH です。URL に `?seed=abc&size=1000&prizes=30` を付けると、同じ展開を再現できます。

## 開発

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
```

main に push すると、GitHub Actions がビルドして GitHub Pages に出します。
