# 演出と音の共通ルール

## 目的

- 後で使い回せる演出の部品を作る。ゲームの処理（core/）、通信（net/）、デモの権威（demo/）、画面（ui/）には依存しない。入力は引数で受け取り、終わりは Promise で返す。
- 目標は、ドーパミンが出る演出（オリパの開封、パチンコの予告・確定演出）。手を抜かず、こだわって作る。

## 画面と座標

- 大画面は 1920×1080、スマホは 390×844 の固定サイズで組む（画面側で縮小表示する）。host は position が relative か absolute の要素。
- 大画面の配置:
  - HUD: 上 0〜90px
  - 抽選機: 左〜中央（x 40〜1240、y 90〜790）
  - 結果パネル: 右（x 1270〜1880、y 110〜500）
  - 会場ビュー: 右（x 1270〜1880、y 520〜780）
  - 番号の盤: 下（y 800〜1060）
  - 抽選機以外の担当は、全画面に重ねてよい。
- スマホは上から、ステータス（〜40px）、段階のバー、名前、リーチの札、カード（5×5）、最新の番号、履歴の順に並ぶ。重ねる演出は host 全体（inset 0）に置く。
- z-index の目安:
  - 大画面: 抽選機 1〜19、画面側のパネル 20〜29、イベント 30〜49、ダブルチャンス 50〜59、粒子 60
  - スマホ: カード 1〜9、あおり 10〜19、単発の演出 20〜29、景品・選択・ガラポン 30〜49

## 見た目

- 背景は濃紺（#05070f〜#16204a）。
- 段階の色は theme.ts の TIER_COLOR（青 #3b82f6、緑 #22c55e、赤 #ef4444、金 #f5c542）。
- 虹は RAINBOW_CSS を hue-rotate で回す。明るさは変えず、色だけを回す。
- 文字はシステムフォント（'Hiragino Sans', 'Yu Gothic UI', 'Meiryo', system-ui）。演出の大きな文字は font-weight 900。
- 画像・音声・フォントのファイルは使わない（CSS、SVG、Canvas で描く）。npm パッケージも追加しない。
- 色だけで情報を伝えない。形（● ▲ ◆ ★ ✦）と文字も重ねる。

## 安全（光過敏への配慮。必ず守る）

- 点滅は、どの要素も 1 秒に 3 回以下。
- 全面が光る演出は、1 回の演出につき 1 回まで。輝度の変化は 20% 以下、立ち上がりは 120ms 以上。
- 赤は点滅に使わない。縞・渦巻・同心円は画面の 1/3 以下の面積で、ゆっくり回す（1 秒に 0.1 回転以下）。
- 揺れは金と虹のときだけ（8px 以内、300ms 以内）。
- prefers-reduced-motion のときは、動きを止めて色と文字だけで伝える（runtime.ts の prefersReducedMotion）。

## 時間

- runtime.ts の Timeline を使う（speed で縮み、cancel で止まる）。setTimeout を直接使わない。CSS アニメーションの長さは tl.ms(x) で決める。
- デモには ×0.5〜×4 の速度切り替えがある。speed が変わっても崩れないようにする。

## 音

- `import { sfx, bgm, engine } from '../../audio'` で、名前だけを呼ぶ。名前の一覧と意味は src/audio/types.ts にある。
- 中身は別の担当が並行して作っている（今は鳴らない仮の実装）。
- 本番ではスマホは既定で音を出さない。デモでは同じ PC から鳴るので、スマホの演出の音は控えめにする。

## 粒子

- src/fx/particles.ts の Particles（Canvas 2D の紙吹雪・火花）を使ってよい。

## ギャラリー

- 自分のフォルダに `*.gallery.ts` を置き、src/fx/gallery.ts の registerGallery で、作った演出や音をすべて登録する。
- `npm run dev` で開いた URL に `?gallery` を付けると、一覧から 1 つずつ再生できる。
- play(host, tl) の host は、screen が 'stage' なら 1920×1080、'phone' なら 390×844 の要素。

## コード

- TypeScript（strict）。コメントは日本語で、既存のコードと同じくらいの量にする。
- CSS は担当の接頭辞を付けたクラス名で書き、TS から import する（例: `import './draw.css'`）。
- 自分の担当ファイル以外は編集しない（読むのはよい）。
- 共通のファイル（theme.ts、runtime.ts、gallery.ts、audio/types.ts、audio/engine.ts、audio/index.ts）に足りないものがあれば、自分のファイルの中に書く。
- 確認は `npx tsc --noEmit` が通ることだけでよい。ブラウザでの確認は、統合のときにまとめて行う。
